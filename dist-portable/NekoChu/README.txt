# NekoChu - Pikachu Desktop Pet (Windows Portable)

## Uso

1. Copia toda la carpeta `NekoChu` a donde quieras
2. Haz doble clic en `NekoChu.exe`
3. ¡Listo!

## Controles

| Acción | Descripción |
|--------|-------------|
| Mover mouse | Pikachu te sigue |
| Click + arrastrar | Arrastra a Pikachu |
| 10s inactivo | Pikachu se duerme |
| Cualquier tecla/movimiento | Despierta a Pikachu |
| ESC | Cerrar aplicación |

## Notas

- No requiere Python ni instalaciones
- Funciona en Windows 7/8/10/11 (64-bit)
- Requiere tarjeta gráfica con soporte OpenGL
- El sprite placeholder es genérico - reemplaza `sprites/pikachu64.png` con el sprite real

## Problemas comunes

**No funciona?** Asegúrate de:
- Usar Windows 64-bit
- Tener permisos de ejecución
- Tarjeta gráfica actualizada

## Créditos

Creado con Python + Pygame
